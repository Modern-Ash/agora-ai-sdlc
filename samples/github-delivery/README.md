# GitHub delivery profile sample

This credential-free sample installs Agora Core's reviewed GitHub Issues, Pull Requests, and Actions
CLI adapters, but never launches `gh`. It prepares three read operations, proves a write is denied,
normalizes a fixture at an immutable commit, records external evidence references, and completes the
AI-SDLC lifecycle.

```console
agora-ai-sdlc run-sample github-delivery
```

The JSON summary reports the prepared operations, commit-bound evidence, idempotent ingest, policy
denial, Core permission denial, final state, and validation result.
