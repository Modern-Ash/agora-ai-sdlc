# Professional Services packages

Modern Ash offers bounded consulting and implementation services around the open-source Agora AI-SDLC distribution. These packages are initial scoping baselines for a statement of work, not prices, warranties, service-level agreements, or promises of business outcome.

| Package | Primary outcome | Typical boundary |
| --- | --- | --- |
| [AI-SDLC Assessment](assessment.md) | Evidence-based current-state baseline and adoption plan | Analysis and recommendations |
| [Starter Pilot](starter-pilot.md) | One team, one repository, one accepted Unit of Work | Non-production pilot |
| [Enterprise Adoption](enterprise-adoption.md) | Governed multi-project rollout using signed project-local snapshots | Self-managed rollout |
| [Legacy Modernization](modernization.md) | One characterized, traced modernization slice | Bounded migration increment |
| [Regulated Delivery Readiness](regulated-readiness.md) | Control mapping, gap register and evidence index for higher-assurance delivery | Non-production readiness; no certification |

Cross-package procurement references:

- [Statement of work template](statement-of-work-template.md): a drafting skeleton for any package, with no prices or guarantees.
- [Vendor-neutral reference architecture](reference-architecture.md): logical boundaries, deployment patterns, replacement points, failure recovery, and optional cloud/on-premises mappings.
- [Security and shared responsibility](security-and-responsibility.md): control-by-control distinction between Agora enforcement, deployment evidence, customer operation, and provider duties.
- [Marketplace listing workspace](marketplace/README.md): draft Professional Services copy, claim substantiation, private-offer input boundaries, and a blocked pre-submission review gate.

## Software and services boundary

Repository software and documentation remain available under [Apache License 2.0](../../LICENSE). The license does not include consulting labor, implementation, training, customer-specific configuration, operational support, provider/cloud charges, or a managed service. Purchasing services does not change the open-source license, and using the software does not require purchasing services.

Each engagement needs a separately agreed statement of work covering scope, schedule, commercial terms, data handling, access, support window, change control, and acceptance owners. Repository examples are credential-free references, not production deployment designs.

## Claim labels

- **Implemented capability:** shipped in the current flavor manifest and exercised by repository tests or samples.
- **Consulting work:** analysis, configuration, facilitation, integration, training, or customer-specific deliverables performed under a statement of work.
- **Goal:** a target agreed after baseline measurement; not a guaranteed percentage or outcome.
- **Customer responsibility:** an input, decision, control, system, or approval the customer owns.

Agora is vendor-neutral and can be deployed with customer-selected infrastructure and runtimes. It is not sponsored, endorsed, or certified by AWS or another cloud/model provider.
