# Incremental modernization

Runs one language- and tool-neutral legacy checkout slice through discovery, characterization, target architecture, conversion, equivalence, cutover and stabilization. The fixture keeps one behavior explicitly unknown, demonstrates a regression blocking operations, and demonstrates missing rollback validation blocking completion.

```bash
uv run agora-ai-sdlc run-sample modernization
```

All state is local and temporary. The scenario uses Agora Core records and the unchanged six-state AI-SDLC lifecycle.
