# Marketplace listing workspace

This directory contains a draft AWS Marketplace **Professional Services** listing package. It is not a product submission, public offer, seller registration, legal approval, or authorization to publish. The draft was prepared against AWS documentation reviewed on 2026-09-20; marketplace fields and requirements must be revalidated in the seller portal before submission.

## Contents

- [Listing copy](listing.md): buyer-facing draft plus field-level completion notes.
- [Claim substantiation](claim-substantiation.md): the evidence and permitted boundary for every material marketing claim.
- [Private-offer inputs](private-offer-inputs.md): customer-specific information to collect and protect outside this public repository.
- [Pre-submission review](review-checklist.md): editorial, legal, security, and marketplace-operations gate.

## Submission boundary

Actual submission is a separate business action and is not authorized by issue #43. The draft deliberately omits prices, customer and buyer identifiers, seller-account details, public support contacts, a logo URL, negotiated terms, and associated-product identifiers. Do not replace placeholders in this public repository with confidential or customer-specific values.

AWS currently requires Professional Services products to relate to an AWS service or public AWS Marketplace product. Merely saying that Agora can run in an AWS environment does not establish listing eligibility. An accountable marketplace owner must identify and validate the relationship before submission.
