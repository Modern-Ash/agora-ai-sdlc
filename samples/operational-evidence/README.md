# Operational evidence sample

Normalizes optional CloudWatch, Azure Monitor, GCP Monitoring, Prometheus, and OpenTelemetry fixtures, binds deployment and smoke evidence to one release, evaluates a real Agora Core control band, and completes the lifecycle without contacting or mutating production.

```bash
uv run agora-ai-sdlc run-sample operational-evidence
```

No provider account, network access, runtime, or credentials are used.
