# Definition of Done

- [ ] Every acceptance criterion satisfied and evidenced.
- [ ] `TESTS.md` and `RESULT.md` complete.
- [ ] Focused and full validation run (or omissions justified).
- [ ] Independent review verdict `approved` or `approved-with-observations`.
- [ ] Changes confined to allowed paths; no unrequested refactors.
- [ ] No credentials or provider-specific dependencies.
- [ ] Documentation updated where behavior or contracts changed.
- [ ] PR opened, linked to the issue; issue closed only after verification.
