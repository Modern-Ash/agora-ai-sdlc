# Codex

Follows [AGENTS.md](../../AGENTS.md); this file only adds usage notes.

1. Start from one issue: `gh issue view <n>`; confirm it is `ready`.
2. Read minimal context: AGENTS.md, the issue, parent epic, and named `.agora/context/` files.
3. Create `.agora/execution/<n>/TASK.md` (planner role) and stop for clarifications.
4. Implement focused changes in allowed paths only.
5. Run focused checks, record in `TESTS.md`.
6. Deliver a compact `RESULT.md` summary. Do not explore unrelated files.
