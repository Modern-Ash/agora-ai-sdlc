# Draft listing: Agora AI-SDLC Professional Services

## Product title

**Agora AI-SDLC Professional Services**

Uniqueness must be checked in the seller portal before submission.

## Short description

Assessment and implementation services for adopting provider-neutral, evidence-driven AI software delivery with Agora in customer-controlled environments, including AWS when selected. [C01] [C02] [C06]

## Long description

Modern Ash helps delivery teams assess, pilot, implement, and govern Agora AI-SDLC, an open-source flavor built on Agora Core. The engagement combines bounded consulting with lifecycle, gate, approval, evidence, policy, profile, and integration capabilities shipped in the current distribution. [C02] [C03] [C08]

Customers can select an AI-SDLC Assessment, Starter Pilot, Enterprise Adoption, or Legacy Modernization scope. Every engagement defines prerequisites, activities, deliverables, customer responsibilities, exclusions, acceptance owners, and measured goals in a statement of work; outcomes are not guaranteed. [C02]

Delivery occurs in customer-controlled repositories and environments. Customer-selected runtimes, model providers, CI systems, scanners, monitoring systems, and infrastructure remain replaceable. The service can be scoped for AWS infrastructure, but Agora does not require AWS. This listing is not AWS-sponsored or AWS-certified. [C01] [C06] [C08]

Agora Core remains the lifecycle authority. External systems remain authoritative for the facts they produce, and customers retain responsibility for identity, credentials, isolation, data residency, provider and model terms, backups, retention, monitoring, and incident response. [C03] [C08]

This listing is for Professional Services, not SaaS. The Apache-2.0 repository software is available separately from paid assessment, configuration, implementation, facilitation, integration, training, and engagement support. [C07] [C09]

Compatibility with public method profiles is evidence-tracked rather than asserted as a blanket claim. Current gaps remain visible in the generated matrix. AWS-original and LG-enterprise statuses are generated from executable repository conformance over their public compatibility profiles; no proprietary implementation behavior is inferred. [C10]

## Highlights

- Choose a bounded assessment, one-repository pilot, self-managed enterprise adoption, or incremental legacy-modernization engagement. [C02]

## Delivery method

The delivery method is a scoped Professional Services engagement purchased through an AWS Marketplace private offer. Before purchase, Modern Ash and the customer agree a statement of work covering the selected package, prerequisites, deliverables, schedule, access, data handling, support window, acceptance, change control, exclusions, and responsibilities. [C02] [C09]

Work is remote-first in customer-controlled repositories and environments. On-site work, production access, cloud provisioning, custom adapters, or ongoing operations occur only when explicitly authorized and technically scoped. The customer operates provider accounts, credentials, infrastructure, deployment, backups, and production decisions. [C08]

The engagement does not provision a multi-tenant Agora service, transfer a SaaS entitlement, or make a hosted Control Plane available. Open-source software installation and use remain governed by Apache License 2.0; the private offer purchases only the services and support stated in its documents. [C07] [C09]
