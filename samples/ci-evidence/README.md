# Generic CI/CD evidence sample

This credential-free sample combines normalized GitHub Actions, GitLab CI, and Jenkins fixtures.
It creates current `test-suite`, `security-scan`, and `deployment` evidence through the same neutral
profile, registers bounded external references in Agora Core, and completes the AI-SDLC lifecycle.

```console
agora-ai-sdlc run-sample ci-evidence
```

No provider CLI, network service, token, log, or environment dump is used.
